# Design-Referenzen

Eingabe für Architekt, Builder und design-guardian: Sie lesen diesen Ordner vor jeder sichtbaren Änderung.

## Ablage

- Je Referenz eine Datei: ein Bild (`.png`, `.webp`) oder eine `.md` mit URL.
- Zu jeder Referenz eine Zeile in der Tabelle unten: was übernommen wird und was nicht.
- Keine fremden Assets (Bilder, Schriften, Icons, Texte) ins Produkt kopieren — Referenzen zeigen Richtung, sie
  liefern kein Material.

## Referenzen

| Datei | Übernehmen | Nicht übernehmen |
|---|---|---|
| [FÜLLUNG] `beispiel-startseite.webp` | Abstände, Schriftgrößen-Stufen | Farben, Bildsprache |
